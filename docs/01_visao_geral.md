# Visão Geral do Projeto

## Nome do Projeto
Sistema local de gestão de pedidos, estoque e produção para empresa de fardamentos.

## Objetivo
Centralizar o controle de pedidos, estoque, produção, mensagens internas e arquivos em um único sistema local.

## Problemas Atuais
- Estoque controlado no olho
- Pedidos espalhados entre WhatsApp, ligação e balcão
- Falhas de comunicação entre setores
- Prazos esquecidos
- Erros de produção
- Falta de histórico e rastreabilidade

## Usuários do Sistema
- Patrão
- Gerente Geral
- Gerente de Produção

## Funcionalidades do MVP
- Cadastro de clientes
- Cadastro de pedidos
- Linha do tempo do pedido
- Controle simples de estoque
- Geração de mensagens prontas
- Upload de arquivos
- Upload e transcrição de áudio
- Controle de prioridades
- Alertas de prazo

## Tecnologias
- Python
- CustomTkinter
- SQLite
- Ollama
- Mistral 7B
- Whisper
- PyInstaller

# Fluxo do Pedido

## Entrada do Pedido
O pedido pode entrar por:
- WhatsApp
- Ligação
- Balcão

## Fluxo Interno

1. Receber encomenda
2. Criar comanda funcional
3. Encaminhar para design
4. Confirmar arte
5. Conferir estoque ou necessidade de corte
6. Enviar exportações para impressão
7. Encaminhar para estamparia, serigrafia ou DTF
8. Encaminhar para costura
9. Cortar linhas e embalar
10. Avisar cliente para retirada
11. Entregar pedido

## Linha do Tempo do Sistema
- Recepção
- Design
- Impressão
- Estamparia
- Costura
- Retorno à Recepção
- Retirada
